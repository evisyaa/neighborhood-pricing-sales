# UPLOAD THIS PROJECT TO GITHUB

1. Extract the ZIP.
2. Open the folder `neighborhood-pricing-sales`.
3. Upload **all contents inside that folder** to your private GitHub repository.
4. Do not upload `.env.local` if you create one locally.
5. Read `README.md` for Supabase + Vercel setup.

Main files you should see in GitHub:

- `app/`
- `components/`
- `lib/`
- `public/`
- `scripts/`
- `supabase/`
- `package.json`
- `README.md`
- `.env.example`
- `.gitignore`
